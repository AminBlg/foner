# Security

Report a vulnerability privately through [GitHub private vulnerability reporting](https://github.com/AminBlg/foner/security/advisories/new). Do not open a public issue for it.

The latest release receives fixes. Older releases do not.

Foner reads the phonebook and the call history from the phone and keeps them on disk. A report about that data reaching another user or another program is in scope.
